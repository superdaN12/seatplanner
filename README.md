# Tischplaner

Eine einfache Web-App zur Gestaltung von Tisch- und Sitzplänen — keine Installation, kein Build-Schritt. Einfach `index.html` im Browser öffnen.

## Features

- Tische hinzufügen (rund/eckig, 1–30 Sitze)
- Tische per Drag & Drop verschieben
- Sitzanzahl nachträglich ändern (entfernt zuerst leere Plätze, fragt nur bei belegten)
- Gästeliste per Textfeld pflegen, Format: `Name | Gruppe`
- Gäste zuweisen per Klick auf Sitz (mit Suchfeld) oder Drag & Drop
- Gruppen werden farblich markiert
- Auto-Zuweisung mit Gruppenpriorisierung
- Übersicht: platziert / offen / Sitze gesamt
- Canvas pannen (Klick + Halten auf leere Fläche) und zoomen (Strg/Cmd + Mausrad oder Buttons)
- Speichern in localStorage, Export/Import als JSON

## Nutzung

```bash
open index.html
```

Oder die Datei in einem beliebigen Browser öffnen.
